Honest limits

  • Direct cross-workspace reads structure over REST, but full SHOW CREATE fidelity needs SQL on the source — so the airgap flow (run inventory+export on the source) is the recommended high-fidelity path and the one verified here.
  • Notebooks compile and wrap the services proven by the local driver, but were not executed as a deployed Databricks job in this pass.
  • Infosec gate is reactive — it fails an object with a precise reason when a governed-tag definition or function is missing — rather than a proactive preflight scan.
  • Materialized views / streaming tables are inventoried and governed but not created (pipeline-backed, by design).
  • An optional job installer (00_Install_Jobs + jobs/*.json) was not built.
